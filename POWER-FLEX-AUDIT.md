# Non-Samsung power/volume flex compatibility audit

This is a research ledger for the non-Samsung screen listings in `products.js`. A model is recorded as a **source-listed match** only when a repair-parts listing title or description explicitly names that handset or handset code. This records the seller's compatibility claim; it is not a fit test of a physical part. Check the exact phone code, flex layout, connector, and revision with the supplier before ordering or fitting.

Samsung models are intentionally excluded. A shared-part claim is recorded only for the exact models named by that particular source; it must not be expanded to nearby models in the family. A blank result or blocked page means **not verified here**, not incompatible.
